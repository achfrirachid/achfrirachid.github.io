النسخ الاحتياطي

💾 نسخ تتبع الطلبة
🔍 استرجاع بالرقم (معزول)
دخل رقم هاتف واحد فقط. غادي تشوف غير البيانات ديال هاد الرقم بالضبط (الاسم، يوم الالتحاق، حالة الخلاص)، بلا ما تتلامس ولا تتخلط مع أي رقم آخر. ماكيبانش والو حتى تدوس "استرجع" — وماكيتزادش للتطبيق حتى تدوس "استورد" بيدك. تقدر ديما تحمل ملف جاهز بالمعلومات بلا ما تستورد شي حاجة.
حفظ عناوين الإيميل
صيفط نسخة على الإيميل ديالك (Gmail)
شارك عبر واتساب أو أي تطبيق آخر
حمّل ملف "تتبع_الطلبة" (JSON) فالهاتف — كيتسجل فمجلد التنزيلات (Downloads)، منفصل تماما على بيانات المتصفح، فحال مسحتي الكاش أو الكوكيز ديال Chrome هاد الملف مايتمسحش. خدام بلا انترنت.
💾 نسخة بطاقة SD / الذاكرة الخارجية دوس الزر باش نجربو ونفعلو الكتابة المباشرة فبطاقة SD/الذاكرة الخارجية ملف واحد بإسم ثابت — كل تعديل كيعوض القديم بلا تراكم. بعد حذف/إعادة تنصيب التطبيق كيبقى محفوظ (المسح اليدوي غير هو لي كيمسحو).
نسخة نصية مقروءة (الأسماء + تاريخ الالتحاق) — تقدر تقراها بعينيك حتى بلا التطبيق
الباكاب التلقائي
استرجاع من ملف باكاب محلي "تتبع_الطلبة" (JSON) — كيزيد الجداد بلا مايمس الموجودين. محمي بالكود السري 🔒
📋 تقرير الطلبة (تصدير) تصدير البيانات بصيغة PDF أو Excel أو Sheets مع جدول الأشهر (9-6) وحالة الخلاص
تراجعتي على استرجاع بالغلط؟

☁️ تسجيل الدخول بـ Google (يفعّل Firebase/Supabase)

ماداخلش بعد — ضروري لـ Supabase
⚠️ هاد الزر ضروري وعندو دور حقيقي: هو تسجيل الدخول بـ Google اللي عليه مبني الهوية (uid) ديالك فـ Firebase — ونفس الـ uid هادا كتعتمد عليه Supabase باش يعرف فين يحفظ/يجيب بياناتك. بلاه، Supabase ما يقدرش يخدم. GitHub وTelegram وWhatsApp خدامين بلاه (كيعتمدو على رقم الهاتف). دوسي عليه أول ما تبدلي الهاتف أو تنصبي التطبيق من جديد — هو اللي كيرجع ليك الصور والبيانات من Firebase/Supabase.

🔐 دخول برقم الهاتف / استرجاع البيانات — خانة احتياطية واحدة

خانة واحدة محمية بالكود الرسمي — دوس وحدد إلى بغيتي تدخل برقم (رشيد/عائشة) ولا تسترجع البيانات من Firebase
استرجاع شامل: كيجمع فنفس الوقت من Firebase + Supabase + Gmail + Telegram + GitHub + Cloudflare KV
صيفط نسخة دابا لـ Firebase

👩‍🏫 بيانات المعلمات (أدمين فقط)

هاد القسم محمي بالكود السري 🔒
كل معلمة دخلت بجيميلها الخاص بياناتها معزولة، وكتبان ليك هنا باش تسترجعها ولا تصدرها بلا ما تختلط مع بياناتك
📂 استيراد ملف معلمة توصلك بالواتساب — كتشوف المعلومات غير للاطلاع، بلا ما تتخلط مع بياناتك

صيفط نسخة دابا لـ Dropbox

⚡ استيراد سريع — كلشي دفعة وحدة

لصقي هنا كل المعلومات مرة وحدة (سطر لكل واحدة، بحال المثال تحت)، ودوسي "استيراد الكل" — التطبيق غادي يوزعهم وحدو على Telegram وGitHub وWhatsApp، بلا ما تدخلي كل خانة فحالها.

📨 نسخة احتياطية عبر Telegram (بلا Gmail خالص)

دير بوت من @BotFather فتليغرام، خد التوكن ديالو، صيفط ليه رسالة، وزور api.telegram.org/bot<TOKEN>/getUpdates باش تلقى chat id ديالك
📌 خاص Chat ID ديال رشيد وChat ID ديال المعلمة. إيلا دخلتي توكن بوت ثاني، التقرير غادي يتصيفط للجوج بوتات فنفس الوقت (نفس Chat IDs).
📊 صيفط تقرير الصورة (جدول الطلبة) — رسالة جديدة كل مرة لرشيد وللمعلمة
📁 صيفط نسخة JSON كاملة (قابلة للاسترجاع) — رسالة جديدة كل مرة
🩺 آخر خطأ وقع فإرسال نسخة JSON لـ Telegram — رشيد ولا عائشة
🩺 آخر خطأ وقع فإرسال تقرير Telegram (صورة الجدول)
🩺 آخر خطأ وقع فإرسال تقرير WhatsApp (صورة الجدول) — رشيد ولا عائشة، على حساب من دخل
🗑️ نظف كل الرسائل/الملفات القديمة العالقة فـ Telegram (تقارير ونسخ JSON)، خلي غير الحالية — لا يمكن التراجع
رجّع آخر نسخة من Telegram — أوتوماتيك، كيدمج بلا حذف
حمّل الملف مباشرة من Telegram للهاتف (بلا دمج فالتطبيق)
